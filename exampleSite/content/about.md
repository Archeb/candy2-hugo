## 关于 Candy2 Hugo

Candy2 Hugo 是一个将原本基于 Vue.js 和 Ghost API 的 Candy2 主题转换为标准 Hugo 静态站点主题的项目。

### 项目背景

原始的 Candy2 主题是一个非常精美的博客主题，采用了独特的横向滚动设计和毛玻璃效果。为了让更多人能够使用这个主题，并享受静态站点生成器的优势，我们将其转换为了 Hugo 主题。

### 特色功能

- ✨ **精美设计** - 保留原主题的所有视觉特色
- 🚀 **极速性能** - Hugo 的构建速度让网站秒开
- 📱 **响应式** - 完美适配桌面和移动设备
- 🎨 **易于定制** - 通过配置文件轻松个性化
- 🔒 **安全可靠** - 静态网站天生安全

### 技术栈

- **Hugo** v0.152.2 - 静态站点生成器
- **CSS3** - 样式设计
- **Markdown** - 内容编写

### 使用方法

1. 克隆本仓库
2. 进入 `hugo` 目录
3. 运行 `hugo server` 启动开发服务器
4. 访问 `http://localhost:1313` 预览
