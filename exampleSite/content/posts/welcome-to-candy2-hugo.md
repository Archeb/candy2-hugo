## 欢迎

欢迎来到 **Candy2 Hugo** 主题！这是一个完全将原始 Vue.js + Ghost API 主题转换为标准 Hugo 博客主题的版本。

### 主要特性

- ✨ 流畅的横向滚动体验
- 🎨 统一风格的响应式主题
- 📱 完美支持移动端
- 🚀 静态站点生成，性能优异
- 💎 保持原有精美的视觉设计

### 技术栈

这个主题使用了以下技术：

- **Hugo** - 超快的静态站点生成器
- **CSS3** - 现代化的样式
- **响应式设计** - 完美适配各种设备

### 代码示例

这是一个简单的代码示例：

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Candy2 Hugo!")
}
```
